# Історія змін

## 2.0.0 · 2026-11-27

**Контент**

- Фактчек усіх 130 карток першого видання за офіційною документацією станом на листопад 2026: ES2025, TypeScript 6/7, React 19.2–19.3 і React Compiler 1.0, Redux Toolkit 2.x, Vite 8, Vitest 5, MSW 3, Playwright 1.65, Core Web Vitals з INP. Виправлено помилки (наприклад, 301 — це Moved Permanently, `identity("Hello")` з `const` дає літеральний тип, приклад тесту без `onSubmit`, поведінка інвалідованого кешу RTK Query без підписників) і зламані псевдотаблиці.
- Усі англомовні відповіді переписано: 2–4 природні речення для відповіді вголос замість одного рядка.
- Додано 72 нові картки: event propagation, async/await, ES modules, mapped types, типізація React, React 19 і Server Components, Context і продуктивність, entity adapter, listener middleware, адаптивна верстка, доступні форми, CSP, Service та Web Workers, HTTP/2–3, flaky-тести, доступність, design system, feature flags, 13 нових задач live coding, 8 карток професійного досвіду та новий розділ «Англійська на співбесіді».
- У картках з’явилися блоки «Можливі уточнення» та «Документація».
- Розширено чекліст (49 пунктів) і план підготовки.

**Інтерфейс**

- Новий дизайн: шапка з пошуком, бічна навігація зі статусами карток і прогресом розділів, панель на головній з картками розділів і статистикою.
- Режим «Співбесіда» з самооцінкою та автопереходом, гарячі клавіші, озвучення англомовних відповідей, запуск і редагування прикладів JavaScript.
- Нові інтерактивні демо: Event Loop, debounce/throttle, specificity. Box Model і батчинг перенесено в спільну систему демо.
- Експорт, імпорт і скидання прогресу; автоматичний перенос прогресу з версії 1.
- Мобільне меню-шухляда, темна тема для діаграм, друк без елементів інтерфейсу.

**Інфраструктура**

- Конфігурація посібника в `handbook.config.json`; той самий рушій використовує QA Interview Handbook.
- Тести контенту (формат карток, дозволені домени документації, запуск прикладів), e2e-тести Playwright, перевірка посилань, CI для GitHub Actions.

## 1.0.0 · 2026-11-27

- Перенесено 122 питання, 8 вправ із відкривними розв’язками та 30 пунктів чекліста з вихідних навчальних матеріалів.
- Додано короткі англомовні формулювання, перехресні посилання, автономний HTML та демонстрацію оновлення React state.
- Робочі назви у прикладах професійного досвіду узагальнено для публічного посібника.
- Фактчек відповідей пропущено за домовленістю.
